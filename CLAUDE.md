# Phphone Compiler & Framework

Please refer to the full agent guide located at [.agents/AGENTS.md](.agents/AGENTS.md) for detailed architecture, encryption rules, CLI commands, and codebase guidelines.

## Quick CLI Reference
- `phphone serve` - Start local development server (Port 3000)
- `phphone build apk --release` - Compile encrypted release APK
- `phphone build aab --release` - Compile encrypted release AAB for Play Store
- `phphone clean` - Clear build & Gradle cache
- `phphone doctor` - Environment diagnostics
